## 🔐 About SEMAS

**SEMAS (Security Event Monitoring and Analytics System)** is a cybersecurity-focused project designed to simplify security event monitoring and threat analysis through a centralized platform.

In today's digital environment, systems generate large volumes of logs and security events. Identifying suspicious activities within this information can be challenging.

SEMAS aims to address this challenge by organizing security logs, applying rule-based detection techniques, correlating related events, and presenting meaningful security insights through an interactive dashboard.

The primary goal is to make security monitoring more structured, accessible, and efficient.

## 🎯 Project Objectives

- Centralize security event monitoring.
- Normalize logs from different sources into a consistent format.
- Identify suspicious activities using predefined detection rules.
- Correlate related security events to identify potential threats.
- Provide a centralized dashboard for security visibility.
- Support incident tracking and security analysis.
- Explore AI-assisted anomaly detection for future enhancements.

## 🚀 Getting Started

Follow these steps to run SEMAS locally.

### Prerequisites

- Node.js
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/Amittt47/SEMAS.git
```

### 2. Navigate to the project

```bash
cd SEMAS
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in your browser

```text
http://localhost:3000
```
